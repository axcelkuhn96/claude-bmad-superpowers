# overrides/ (no repo)

Esta pasta é só um marcador. Os **overrides do usuário** ficam em:

```
~/.claude/cbs-overrides/
```

Veja a documentação completa em `~/.claude/cbs-overrides/README.md` após instalar o pacote.

**Por que existe aqui?** Pra deixar claro no repo público que o sistema de camadas existe. Não precisa adicionar nada aqui — usuários customizam no `~/.claude/cbs-overrides/` local deles.
